# RemoteScreen Free MVP

Screen sharing MVP untuk HP Android milik sendiri ke laptop.

Build APK tanpa Android Studio:
1. Upload isi folder ini ke GitHub.
2. Buka Actions.
3. Pilih Build Android APK.
4. Run workflow.
5. Download artifact RemoteScreen-APK.

MVP ini hanya live screen sharing menggunakan MediaProjection + WebSocket.
Tidak ada kamera, mikrofon, atau remote control.

Untuk jaringan berbeda, server harus dapat dijangkau dari internet (misalnya tunnel HTTPS yang kamu kendalikan atau VPS).
